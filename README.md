# مَدار | Madar Study Planner ✦

یک برنامه‌ریز مطالعه ساده، فارسی، راست‌به‌چپ و واکنش‌گرا که **بدون نصب هیچ کتابخانه‌ای** در مرورگر اجرا می‌شود.

## امکانات

- اضافه کردن، تکمیل و حذف کارهای مطالعه
- انتخاب اولویت برای هر کار
- فیلتر کردن کارهای انجام‌شده و باقی‌مانده
- نمایش آمار و درصد پیشرفت
- ذخیره خودکار کارها روی همین مرورگر با `localStorage`
- تایمر ۲۵ دقیقه‌ای تمرکز، توقف و بازنشانی
- نمایش مناسب روی موبایل و کامپیوتر

## اجرا

فایل `index.html` را با مرورگر Chrome یا Edge باز کنید. نیاز به سرور یا اینترنت نیست.

## فایل‌ها

- `index.html` ساختار صفحه
- `styles.css` طراحی و واکنش‌گرایی
- `script.js` منطق برنامه و ذخیره کارها
- `README.md` توضیحات پروژه

## ایده‌های توسعه بعدی

افزودن تایمر استراحت، نمودار مطالعه هفتگی، حالت تاریک و امکان خروجی گرفتن از کارها.
